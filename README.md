# dsh-plugin-core

DSH（DeepSeek Harness）插件共享底座：把跨插件复用的样式与通用功能收敛到一处，
我自己的 DSH 插件通过 npm 引用，不再一个个仓库抄样式、抄文件浏览。

> **状态**：📝 占位（仓已建，内容待填）

## 规划中的入口

| 引入路径 | 内容 |
|---|---|
| `dsh-plugin-core/ui` | token 层 + 样式注入器 + 基础控件 + 日期时间 |
| `dsh-plugin-core/files` | 文件浏览 / 预览 |

## 为什么不拆多包

一个包 + 子路径导出。使用时 tree-shaking 掉没引入的部分，产物大小与拆包一致；
换来的是一仓一版、零跨包协调。模块多到依赖区间互相打架时再拆，`files` 是头号候选。
