2026-11-13 核实（`curl` 拉 5 个库的在线 CSS + 读源码）：

- **现有配置三项全错**：`src/ui/display/Icon.ts:30-37` 写的是 url `font_5252865_mu5upqjaqf`、`baseClass: 'dshpc-icons-base'`、`prefix: 'dshpc-i-'`；真实 CSS 是 `font_5252865_zv3n1s2zg3e`、基类 `.dshpc-i-base`、glyph 类名 `.dshpc-i-base-{name}`。拼出来是 `class="dshpc-icons-base dshpc-i-jian"`，两个类都不存在 ⇒ 图标渲染为空位，且因为库 id 在表里不会告警。
- 各库实际图标数：`common.base` 39、`common.logo` 4；`common.base.color` / `common.logo.color` / `dsh-plugin-core.base` 各 **1 个且名字是 `_`**（iconfont 占位，说明这三个库还没上图标）。
- 全部 5 个库均为 **font-class 模式**（`@font-face` + `.prefix-name:before{content}`），`Icon` 的 `<i class="baseClass prefix+name">` 结构可用。
- 两个 `.color` 库 CSS 里带 `/* Color fonts */`，是彩色字体（颜色随字形，不受 CSS `color` 影响）；大小仍由内联 `fontSize` 控制。
- `src/` 内**没有任何地方使用 `Icon` 组件**（`base:` 只出现在文档示例）；实际 27 个文件直接 `import { IconXxxOutlineRegular } from official`。
- `parseFontCss`（`src/ui/display/icon-parse.ts:40`）按 CSS 结构反推 family / baseClass / prefix，能正确解析这些库 —— 错的是手写的 `ICON_FONTS` 常量没跟上平台重发布。
