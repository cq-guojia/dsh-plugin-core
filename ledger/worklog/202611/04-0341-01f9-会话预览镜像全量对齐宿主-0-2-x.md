## Process

- 宿主 0.2.x 把「运行中」从 turn 过程行搬到 `ChatView` 的 `RunningStatus`：`TurnProcessNodeView` 在 `turn.status !== "closed"` 时直接 `return null`（lib/client.js:6656），运行态由流末尾 `div.running` 渲染（lib/client.js:5599-5637）。已在 `src/session/mirror/RunningStatus.ts` 按官方 1:1 复刻（鲸尾 APNG mask + `TextShimmer`），`SessionViewModal.ts` 按官方 `runningStartTime` 判据（流末尾节点所属 turn 为 open）挂载。
- `formatRunDuration` 在 0.2.x 改成返回 parts 数组（`{text, numeric}`，lib/client.js:5067-5095），文案模板不再带占位：`message.turnProcess.took` = 「已完成，用时 」、`worked` = 「已完成」、单位是 `duration.secondUnit/minuteUnit/hourUnit`。已同步 `message-chrome.ts` + `i18n.ts`，`TurnProcessNodeView` 的数字段套 `durationNumber`（等宽 tabular-nums）。
- `ReasoningRow` 0.2.x：running 时整行由 `DisclosureRow` 的 `TextShimmer active` 驱动，summary 要额外套一层 `TextShimmer`（decorative copy）并带 `data-streaming`、separator 带 `data-shimmer-decoration`；正文 `MarkdownText` 要传 `streaming: running`；`data-state=running` 时还有 `visuallyHidden` 的 `row.running`（中文「运行中」）。旧版那条灰色扫光动画已从官方 CSS 删除。
- `MessageIconActions` 只有 `timeStart` / `timeEnd` 两个语义名（`clock` 从来不存在，之前的 `clock` 兜底已删）。
- `UserContent`（0.2.x）：附件行 `attachmentRow` 在气泡**之前**；文件名元信息 = `fileExtension(name).toUpperCase().slice(0,8)` + `fileSizeText(bytes)`（无空格，如 `MD 12KB`），不是旧的自绘 `formatBytes`。
- `TurnTriggerNodeView`：`schedule` 图标改成 `IconClockOutlineRegular`；header 带 `aria-controls`；展开体是 `ModelFacingContent`（每条文本一个 `pre[data-context-text]`，超 20000 字符截断）。
- `TurnTailNodeView`：`data-actions-reveal = endsWithResponse ? "always" : "hover"`（旧实现恒 `always`，是 2026-09-27 的偏差拍板，本次按「与宿主一致」改回官方判据）；`branchUnavailable = data.branchUnavailable || hasLaterChatNode`。
- `ChatViewFrame`：补官方 `div.turnSpacer[data-chat-turn-spacer]`（`height:0` 滚动锚点）与 `root[data-chat-following-tail]`。
- 自检跟着行为改：`test/session.test.mjs:187` 的 `formatRunDuration` 断言改成 parts 语义（官方 0.2.x 秒不补零：`1分5秒` / `1m 5s`），字典键表换 `duration*Unit` 并补 `chatDeepDivingFor` / `reasoningRunning` / `jsonTruncated`。
- `PresentRow`（ui-deliverables@0.2.1-rc.5 lib/client.js:508-563）：preparing 与 started 是**两个组件**——preparing 是瘦行（root 无 class、`aria-label=row.preparing`、`DisclosureRow` 只带 title/icon/open:false/expandable:false/running:true），started 的 root 也不挂任何 class（我们之前套了 `ToolRow/root` 等四层类名）；`children` 是数组且 `pre.output` 恒在。
- 交付网格 `data-after-changes` / `data-single`（单文件整行铺满）；`cardPreview` 按钮与 `previewHint` 官方恒渲染。
- `ToolRow.chevron` / `imageLabel` 在 0.2.x 语义表里已不存在（箭头样式并入 primitives `DisclosureRow`），我们传的 `chevronClassName` 恒空串，已删。
- 工具卡的结构性缺口（bash/read/write/grep/web/todo/details 在官方都是专属卡）已记入 To Do 按行推进——这是「全部对齐」里最大的一块。
