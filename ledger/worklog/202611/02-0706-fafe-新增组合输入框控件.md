## Process

- 命名定为 `InputGroup`（与 `SplitGroup` 对称），**不改造** `SplitGroup`：后者明确固定两格且不持状态，而本控件要多枚按钮 + 输入值 + 撤销栈，属于两种东西（`src/ui/SplitGroup.ts:8` 的「固定两格」是用户 2026-10-28 拍板）。
- 撤销口径（用户原话只说「支持撤销」，语义未定，按最省事且可解释的实现）：**Enter / 失焦 / 点任一 action = 一次提交**，提交前的值压栈；点撤销弹回栈顶，栈空时按钮禁用。父级直接改 `value`（外部清空）不算编辑、不进栈。实现见 `src/ui/InputGroup.ts:96-110`。
- 高度：根节点内联 `height`，内件一律 `height:100%`（`src/ui/controls/input-group.css:11`）。**不能只靠 `align-items:stretch`** —— input 有确定高度时 flex 不会拉伸它；分隔线规则也得写成 0,2,0 并排在 `border:0` 之后，否则被清边框规则压掉（`input-group.css:37-43`）。
- 内件复用现成的 `Input` / `Button` / `IconButton`（不另写一套输入框皮肤），样式靠 `.dshpc-igroup > .dshpc-input` 这类 0,2,0 规则把它们的外框交出来 —— 与 `split-group.css` 同一套做法。
- 生成链：`scripts/gen-css.mjs` 的 MAP 加一行 → `src/ui/controls-css.ts` re-export → 组件 `ensureComponentStyles('input-group', …)`（按需注入，不回到全量）。
- 文档：`docs/help/ui.doc.ts` 新增 topic `input-group`（prose + api `ui-input-group` + code），`gen-docs` 同步出 `docs/help/ui.md` 与 `packages/demo/src/doc-data.generated.ts`；`docs/design/structure.md` 两处清单补行。
- 验证：`pnpm run build` / `pnpm run typecheck` 干净；`pnpm test` 220 条全绿（新增 1 条 `test/ui.test.mjs:52`，覆盖标题→输入框→撤销→动作顺序、icon-only 退化、height 内联）；`pnpm run build:demo` 产物含 `dshpc-igroup`。
- 按钮配色三轮（用户 2026-11-02 逐个点名）：`outline` 白底丑 ⇒ 改 `secondary` 灰面；再定「统一 business 色」⇒ `primary` + `color: var(--dshpc-business)`；第三次推翻自定义色 —— **「用语义色去组成，别自己调」**，最终定：默认 `info`，语义色直接传 Button 现成的档（`success` / `info` / `warning` / `danger`），`action.color` 字段整个删掉（`src/ui/InputGroup.ts:144-160`）。demo 与文档示例改用 `success` 展示。
