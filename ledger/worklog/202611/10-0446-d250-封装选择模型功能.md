## Background

2026-11-10 用户转来 issue「不能选内置账号登录的供应商」，让核查核心「选模型的地方」是否有问题。
核查读到 `src/host/index.ts:47-64`（`buildModelRoutes` 对列不出模型的供应商 `continue`、
异常也静默跳过）、`src/ui/infra/host-data.ts:200-211`（`connectHost` 一次性 fetch 目录，之后不刷新）；
解包官方 `@deepseek-ai/dsh-llm@0.2.2-rc.1` 与 `dsh-api-session-controller@0.2.2-rc.1` 后确认
官方 `session/modelCatalog()` 的 `buildModelCatalog` 同样走 `ctx.llm.listProviders()` +
`listModels()`，账号供应商 `deepseek-account` 的 `discoverModels` 依赖账号登录态与 `/models` 拉取。
**现象根因未落实**（缺真机读数），用户随即叫停该调查（原话「先停了吧」）⇒ 本任务不修那个 bug。

用户接着拍板：核心要把「选择模型」作为独立封装提供，不要让各插件自己再加；三种形态明确为
① 单个下拉、按供应商分组；② 单个下拉、带搜索、「厂商-模型」平铺不分组；
③ 两个下拉联动（先选厂商再选模型），厂商框与模型框都带搜索。
所有搜索框、所有下拉框都要能由消费方定义 width / minWidth / maxWidth，
特别是第③种的两个框要能分别设宽。

核查后确认：核心**已有** `ModelPicker`（`src/ui/inputs/ModelPicker.ts`，自带宿主目录、
`grouped` / `cascade` 两形态），demo 只在 `packages/demo/src/sections/controls.tsx:1061-1074`
把它当示例渲染，没有另封组件。真正缺的是：没有第②种平铺形态；
`ModelPickerProps`（`ModelPicker.ts:23-52`）没透出 `Picker` 已有的 width / minWidth / maxWidth；
`Picker` 的搜索框写死 `width:100%`（`src/ui/inputs/picker.css:37-41`）没有宽度轴；
第③种厂商框写死 `searchable: false`（`ModelPicker.ts:132`）。
⇒ 结论：可行且应该封装，在现有 `ModelPicker` 上补齐，不另起组件、不改数据通路。

- 复核发现 3 个问题并全部调整：① 搜索框自定义宽度被菜单 `overflow:hidden` 裁掉

  ② `test/model-picker.test.mjs` 未跟踪；③ `WorkspacePicker` 未透传宽度 / `translate` 未透传给内部 Picker。

  菜单 `minWidth` 用 `max(触发器宽, calc(搜索框下限 + 8px))`，`Picker.ts` 的 `floatingSize.apply` 改用它；
  CSS 规范里 min-width 大于 max-width 时以 min 为准，故显式设宽不会被 480 上限卡住。
  8px 来自 head 内距，新增契约自检盯住，改 CSS 必须同步。
- ③ 的调整：`WorkspacePicker` 改为 `extends PickerSizing`，新增 `searchSizing`，透传宽度三轴与

  两个领域选择器都补 `useSyncExternalStore` 的 `getServerSnapshot`（客户端行为不变，Node 可渲染自检）。

## Conclusion

- `ModelPicker` 现有 `grouped` / `flat` / `cascade` 三种形态，共用同一份宿主目录数据，
  `onChange` 仍统一发 `provider/id`；数据通路（`serveModelCatalog` → `connectHost`）未改动。
- 触发器与所有搜索框都有 width / minWidth / maxWidth 三轴；cascade 厂商框与模型框
  可经 `providerSizing` / `modelSizing` 分别设宽；菜单随搜索框下限自动加宽，不再裁掉。
- `WorkspacePicker` 补齐同样的宽度轴与 `translate` 透传，两个领域选择器口径一致。
- 验证边界：搜索框菜单经 `FloatingPortal` 在展开后才挂载，Node 无 DOM，
  展开态实际宽度只验到解析函数、CSS 契约与内联绑定，真机仍建议点开 demo 看一眼。
- 新自检文件 `test/model-picker.test.mjs` 随发版提交入库；原 issue 根因仍未落实（已叫停），不在本任务内。
