## Process

- 组件层：`ConfirmModal` 新增 `confirmLoading` / `cancelLoading`，`AlertModal` 新增 `confirmLoading`；`busy` 时把 `onClose` 置 `undefined`（遮罩 / Esc 都走它，等于封死），按钮透传 `Button` 的 `loading`（自带转圈 + disabled，防连点）。源码见 `src/ui/ConfirmModal.ts:40`、`src/ui/AlertModal.ts:52`。
- 命令式层：`confirmModal` / `alertModal` 的 `onConfirm` / `onCancel` 改为可返回 thenable（`DialogHandler = () => unknown`）。同步返回值行为不变；返回 thenable 时先 `draw()` 出 loading，`await` 后 resolve→关闭（confirm 带 `true/false`），reject→撤回 loading 并 `console.error`，弹窗留着重试。见 `src/ui/modal-host.ts:77`。
- 自检：`test/ui.test.mjs` 加了两个用例（只有对应钮转圈/禁用、默认不转圈）。`pnpm build && pnpm test` 241 全过；`koc-codelint` 六层全过（首次报 biome「void is confusing inside a union type」，已把 `() => void | Promise<unknown>` 改成 `() => unknown`）。
