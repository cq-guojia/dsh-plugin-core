## Process

- 解包脚本按 `const css$N = "…" + require.asset(…) + "…"` 顺序配对 `const tagId$N`（官方 CSS 字符串会拼接图片资源，只取第一个字符串字面量会漏掉后半段规则，第一版分析因此误报了 `.older` / `.toBottom` 被删）。
- 精确比对结论：`data-plugin-css` 前缀仍是 4 个包、`@deepseek-ai/dsh-client-ui-chat/ChatView.module.css` 一类标识不变，哈希仍是 `<hash>_<语义名>`；本仓 172 个 `officialClass` 语义对在 0.2.2-rc.1 里**只有 `MessageItem.bubble` 取不到**。
- `ChatView` 语义名新增 `textInteraction`（旧 20 → 新 21）；`MessageItem` 删 `bubble`（32→31）；`TextPreview` 删 `lineTarget`、加 `content` / `lineMark`（本仓未用）。
- 官方 `ui-chat/lib/client.js:9393` 的 `UserContent` 唯一结构变化：`div.MessageItem.bubble` → `primitives.UserMessageBubble`，并带 `data-message-bubble=""` 与 `data-text-interaction-source=""`。该原语在 `dsh-client-ui-primitives@0.2.2-rc.1` 新增（`lib/types/UserMessageBubble.d.ts` 声明 = 原生 div props；`lib/UserMessageBubble.module.css` 的 `.bubble` 保留原背景/圆角/内距）。0.2.1-rc.5 无此原语。
- 主题 token 对照：0.2.2-rc.1 只删 `--dsw-specific-sidebar-nav-item-hover`、加 12 个、改 1 个值；本仓 `tokens.css` 引用的 49 个 `--dsw-*` 全部仍在，明暗判据仍是 `body[data-ds-dark-theme]`。`uiConversation.target('chat')` / `binding` 实现未变。
