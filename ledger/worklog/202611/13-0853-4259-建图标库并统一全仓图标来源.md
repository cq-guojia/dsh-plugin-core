1. 注入 —— 唯一实现点 `src/ui/icons/fonts.ts`，**注册表**形态（多库留位靠它）：
   ```ts
   export const ICON_FONTS = {
     base: {
       url: 'https://at.alicdn.com/t/c/font_5252865_mu5upqjaqf.css',
       family: 'dshpc-icons-base',   // @font-face 的 font-family
       baseClass: 'dshpc-icons-base',
       prefix: 'dshpc-i-',           // glyph 类名前半段
     },
   }
   ```
   `ensureIconFont(set = 'base')`：用 `link[data-dshpc-icon-font="<set>"]` 判重；
   **已存在但 `href` 不同 ⇒ 直接改 `link.href`**（iconfont 重发布换哈希、或整库换 URL 都只改这一处，
   且永远只留一条 link）；`typeof document === 'undefined'` 直接 return；首次渲染 `Icon` 时触发，不在 import 期做。
   以后加社交类图标库 = 注册表多一行 + `<Icon set="social" name="github" />`，`Icon` 内不硬编码 `dshpc-i-`。
2. 尺寸：沿用 `.dshpc-icons-base`（它给字体族 + 默认 16px），尺寸由组件 inline `style.fontSize` 给，
   默认 `1em` 跟随父字号 —— 不依赖远程 CSS 与本仓样式的加载顺序，也不需要自己再写一份 CSS。
3. 契约（2026-11-13 定）：**`name` 直接用 iconfont 的名字**（`shanchu` / `shezhi1` / `xihuan-a`），
   不建语义别名、不做映射表。参照 `mp-taro-kit` 的 `src/ui/icon/base/names.ts`（生成物头部明写
   「不作为对外契约，调用处直接用图标名即可」）。名字清单由生成器从同一个 URL 产出，供展示页遍历
   与 `name` 联合类型收紧，不手写、不"梳理"。
4. 展示：`packages/demo/src/sections/IconsPage.tsx`，遍历上述清单（远程 CSS 的 CSSOM 跨域读不到），
   点名字复制用法，顶栏显示注册表里当前 URL。
5. 消费方：`import { Icon } from 'dsh-plugin-core/ui/icons'` → `<Icon name="gou" size={18} />`；
   不 import CSS、不插 link、不关心 URL。入口登记 `scripts/ui-entries.mjs` + `package.json` exports。
6. 可照抄 `mp-taro-kit` 的：`SOURCES` 注册表（一项目=一字体=一前缀）、`iconClass()` 一处拼类名、
   解析不到基础类直接抛错；**不照抄**的：它把平台 CSS 复制成本地 `style/index.scss`（小程序不能外链样式才这么做），
   我们走远程 `<link>`，故它「生成期剥掉基础类 font-size」这一步在我们这拿不到，尺寸改由组件给。

## Process

- iconfont CSS 二次实拉复核（2026-11-13）：`@font-face { font-family: "dshpc-icons-base" }`；
  `.dshpc-icons-base { font-family: "dshpc-icons-base" !important; font-size: 16px; … }` ——
  **`!important` 只在 `font-family` 上，`font-size: 16px` 是普通声明**。前一版记录写成
  「`font-size: 16px !important`」是读错，已纠正；这也解释了为何此前改字号一直有效（用户 inline / 更具体选择器直接压过它）。
  glyph 全部是 `.dshpc-i-xxx:before { content }`，共 34 条。
- 协议相对地址 `//at.alicdn.com/…` 在代码里要写死 `https:`，别原样照抄。
- 官方图标清单见 `src/types/primitives.d.ts`（41 个），**无 Calendar / Folder 以外的文件类缺口待核** ——
  日历图标官方无原件，这是「必须补我们库」的实证例子。
- 展示页落 `packages/demo/src/sections/`（已有 SectionGroup/Page 套路），远程 `<link>` 放 demo `index.html`；
  组件库自身注入是给第三方消费者的，两处互不依赖。
- 风险：远程 CSS 被宿主 CSP / 内网拦下时图标全空白 —— 先实测一次再谈退路（本地化已被用户否决）。
