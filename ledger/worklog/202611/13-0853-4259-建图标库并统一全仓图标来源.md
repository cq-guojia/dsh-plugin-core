## Next

1. 先只做纯新增的第一刀（不动任何现有控件）：`src/ui/icons/Icon.tsx` + `src/ui/icons/icon.css`
   （gen-css MAP 加一行）+ `names.ts`；`ensureIconFont()` 按 id 判重注入
   `https://at.alicdn.com/t/c/font_5252865_mu5upqjaqf.css`。
2. 关键实现点（已核实，绕开坑）：**不要用 iconfont 的 `.dshpc-icons-base` 类** —— 它带
   `font-size: 16px !important`，会把尺寸轴锁死且 inline style 也压不过；只用它提供的
   `dshpc-i-*:before { content }`，字体族/对齐/尺寸由我们自己的 `.dshpc-icon` 声明。
3. 对外 API：`Icon({ name, size?, title?, className? })`，`name` 走我们自己的语义名
   （`check` / `close` / `plus` / `minus` / `star` / `star-filled` …），**不把 `shezhi1`、
   `xihuan-a`、`iconjia` 这类 pinyin 名当契约** —— iconfont 侧重传会漂，语义名表是唯二稳定面。
4. 出盘点表后一次性把「缺什么图标」清单交给用户在 iconfont 侧补（我们只能提单，不能改远程）。
5. 迁移分批：字符 glyph → 自绘 chevron/folder/calendar（calendar 官方无原件，需补库）→ 官方那批按①的结论处理。
