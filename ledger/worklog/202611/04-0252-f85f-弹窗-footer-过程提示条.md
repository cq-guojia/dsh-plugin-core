## Background

用户 2026-11-04 原话：弹窗（alert / confirm 以及所有带 footer 的）在 loading 期间需要一个**底栏左侧**的
过程提示位 —— 可以逐步换文案（第一步在干嘛、第二步在干嘛），切换要「飞机牌」那种上下翻动；
文本太长三点省略、hover 跑马灯；**必须单行**；开启是可选能力。

用户当时提的两个疑问，当场拍板：

1. **提炼还是塞进弹窗里** → 拆两层、不做引擎：控件 `FlipText`（`text` 变了就翻）+ 弹窗只做挂载位与透传。
   理由：跑马灯已有 `MarqueeText`、可复用；SideSheet 底栏 / 表格刷新条 / 加载页都会用到同一套。
2. **消费端要方便** → 调用方只 setState 换字符串，不手搓动画、不监听 loading、不管步骤队列。

宽度要求（用户点名）：抽象出来之后要能适配各种场合 —— 能定宽、能设最大宽。

## Process

- 尺寸/溢出全复用 `MarqueeText`（`src/ui/MarqueeText.ts:15`），本组件只做「两层同格叠放 + 裁剪」，
  没有第二份测宽代码。
- 叠放用 `display:grid` + `grid-area:1/1` 而不是绝对定位：容器高度天然等于一行，
  既不测量也不用 `lh` 单位（`src/ui/flip.css`）。
- 换字在 render 期调 state（`nextFlipSlot`），同一次渲染就带新值，不会先闪一帧旧帧。
  `seq` 只用来换 key，让两层每次重新挂载、动画从头播。
- 旧帧清除**不能只靠 `onAnimationEnd`**：`prefers-reduced-motion: reduce` 下动画被 `animation:none` 关掉，
  事件永远不来 ⇒ 旧帧一直压在新帧上（同格叠放，两层都可见），文字重影。改成 `useEffect` + 300ms 定时器
  兜底，并在 media query 里给 `.dshpc-flip__out` 补 `opacity:0`（2026-11-04 复查时发现）。
- 空串语义（2026-11-04 用户补充）：`text === ''` 时组件返回 `null` —— 不渲染、不占位；
  `nextFlipSlot` 遇到「上一帧是空串」不设 prev ⇒ 清场后的第一句直接出现，不从下方翻上来。
  弹窗侧同样把 `notice === ''` 当没给（`Modal` / `SideSheet` 各做一次归一），这样同一块底栏复用下一轮时
  传空串就清干净。
- 同一个 `replace_in_file` 改大段 JSX 时踩过两次「报成功但内容没变」，改完必须回读确认（本轮 demo 就是这么
  多绕了两轮 tsc）。
- 底栏 `justify-content:flex-end` 不变，notice 靠 `flex:1 1 auto` 吃掉按钮之外的剩余宽；
  漏掉 `min-width:0` 三点省略永远不生效（flex 子项默认 `min-width:auto`）。
- `sm` 档 footer `padding:0`（`src/ui/feedback.css:32`），notice 与面板 18px 内距对齐，不需要额外补。
- 新 CSS 要同时登记两处：`scripts/gen-css.mjs` 的 MAP（否则生成物闸红）与
  `test/css-contract.test.mjs` 的 CONSTANTS（否则不参与 `var()` 来源检查）。

## Conclusion

- 新控件 `FlipText`（`src/ui/FlipText.ts`，样式真源 `src/ui/flip.css`）：`text` / `width` / `minWidth` / `maxWidth` / `className`；
  宽度三档与 Button / Chip 同口径，全不传 = 随父容器。已从 `src/ui/index.ts` 导出。
- `Modal` / `ConfirmModal` / `AlertModal` / `SideSheet` 各加 `notice?: string`；不传 = 不占位，
  与接入前完全一样；`Modal` 允许只给 notice 不给 footer（自己撑起底栏）。
  命令式 `confirmModal` / `alertModal` 经 `ConfirmOptions` / `AlertOptions` 自动带上该字段。
- 空串 = 清场（2026-11-04 用户补充）：`FlipText text=''` 整行不渲染；弹窗 `notice=''` 连底栏都不出。
- demo：FlipText 从「标签 · 文本 · 状态」页挪到**独立页**（组件组 → `翻牌文本`，`packages/demo/src/sections/controls.tsx`
  的 `FlipTextPage`），带「下一步 / 清空（传空串）」两个按钮；反馈页的过程提示每一步停留改成 1.5 秒，
  且打开时留 900ms 空场再出第一句，用来演示「刚进去没有、设置了才有」。
- 自检：`nextFlipSlot`（同句不重播 / 换句降帧递增 seq / 空串后第一句不翻）、`Modal` 有 notice 才出底栏、
  `notice=''` 不出底栏、`FlipText text=''` 渲染空串 —— 全绿。
