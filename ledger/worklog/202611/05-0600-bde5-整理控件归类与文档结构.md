## Process

- **业界分类依据**（2026-11-05 抓取，版本为当日站点所见）：Ant Design 6.7.0 七组（通用/布局/导航/数据录入/数据展示/反馈/其他）；Element Plus 2.14.6 七组（基础/配置/表单/数据展示/导航/反馈/其他）；MUI 9.5.0 八组（Inputs/Data display/Feedback/Surfaces/Navigation/Layout/Utils + X/Lab）；Mantine 9.7.5 十组（含独立的 Buttons / Overlays / Typography / Miscellaneous）；Chakra 3.38.0 十一组；shadcn/ui 不分（字母序）。Arco / Vant 站点是 SPA，静态抓不到内容，**未采用**。
- **共性五类**：布局 / 导航 / 录入 / 展示 / 反馈 —— 五个库全部覆盖。每家另有一格装**基础设施**（AntD「其他」、Mantine「Miscellaneous」、Chakra「Utilities」），装的都是 ConfigProvider / Portal / Divider / Transition 这类非控件。
- **分歧按多数派裁决**：Segmented → 录入（MUI/Mantine/Chakra 3 : AntD/Element 2）；Pagination → 导航（AntD/Mantine/Arco/Vant 4 : Element 1）；Tooltip/FieldHint → 展示；Card/Surface → 展示（仅 MUI 单列 Surfaces）。Button 无共识（通用 vs 单列 Buttons），取单列「动作」，先例是 Mantine / Chakra。
- **现状证据**：`src/ui/` 根平铺 50+ 个 `.ts`，唯一子目录 `controls/` 里只有 15 个 css + 15 个 `*.generated.ts` —— 一个控件的 ts / logic / css 分居三层。`CodeViewer`、`host-toast` 因无处安放各自开了子路径（`package.json:35-42`）。demo 侧栏 5 组 23 页，13 个控件页平铺、分类不可见（`packages/demo/src/sections/index.tsx:30-109`）。
- **被推翻的方案**：首轮提出的「按控件自己持有什么」判定法被判为拍脑门（用户原话「你这个还是拍脑门了」），改用业界通名 + 多数派。

## Conclusion

共识（用户 2026-11-05 逐条确认）：

1. **7 类，用业界通名**：动作 / 录入 / 展示 / 反馈 / 布局 / 导航，加 `infra`（基础设施：style-kit、official、host 桥、tooltip renderer、locale、resizer、ticker、thenable、图标）。infra 不进导航、不算控件。
2. **代码目录**：`src/ui/{actions,inputs,display,feedback,layout,navigation,infra}/`；一个控件的 `.ts` + `*-logic.ts` + `.css` + `.generated.ts` 同目录。
3. **结构优先，不为兼容让步**（用户 2026-11-05 追加拍板：「不要为了保持现在消费方不改，而你去用一个不合理的结构……如果有必要的话，我让消费方去改」）：
   - 目录与命名按最合理来定；消费方的改动由用户统一安排复查，agent 不预先查消费方仓库。
   - 因此这次一并做 `src/explorer` → `src/adv.explorer`、`src/session` → `src/adv.session`（`structure.md` 旧未落地项），`package.json` 的两条子路径同步改。
   - 对外仍取**单入口** `dsh-plugin-core/ui`（理由是 AntD / MUI 同为单入口、按类开子路径只增加记忆成本而无收益，**不是**为了兼容）；
     保留 `ui/official`（L1 adapter）与 `ui/code-viewer`（CodeMirror 太重，`src/ui/CodeViewer.ts:18`，按需加载的理由成立）；
     `ui/host` 只有「避开 Node 单测静态 import 官方件」的技术理由、无分类含义（`src/ui/host-toast.ts:24`），本次按语义改名。
4. **demo 侧栏 2 级 17 页**：入门(3) / 设计(1) / 控件(6) / 应用模块(2) / 工具方法(5)。控件 13 页合并为 6 页（动作 / 录入 / 展示 / 反馈 / 布局 / 导航），分页从表格页拆出；参考页由一级降为「入门」下的二级。
5. **应用模块单开一级**，下辖 文件浏览 / 会话预览 两项。
