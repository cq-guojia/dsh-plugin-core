**API 定稿（2026-10-20 二次修正，按成熟库规范）**：结构写 children，显隐按名 ——

- `<PanelDock dock={dock}>{<DockPanel id="files" …>…</DockPanel>}</PanelDock>`；
- `dock.open(id?)` / `close(id?, reason?)` / `toggle(id)` **只传 id，不传内容**；
- 头部：`title` / `icon` / `extra`（标题右侧任意内容）三件套；`header` 整块替换；`header={null}` 不要头部；
- 关钮：`closable` / `closeButton: auto | header | floating | none` / `closeIcon`；
- 宽度：`width` / `minWidth` / `maxWidth`（业务上下限，拖到头即停）；
- 事件：`onOpen` / `onBeforeClose`（可返回 false 取消）/ `onClose` / `onResize` / `onLimitReached`，全部带 `{ id, … }`。

**同规范排查结论（本仓其他控件）**：`Modal` 已是 `title` + `headerExtra` + `hideHeader` + `children` 的声明式（合规范）；`confirmModal` / `showToast` 属"无归属的瞬时层"，与 Ant Design `Modal.confirm` / `message` 同款，收字符串或轻量 props，不算违规；`Picker` / `Card` / `Chip` / `ExplorerPanel` / `SessionPreview` 均以 props 数据或 children 组成，无"把页面树塞进调用"的问题。**只有 PanelDock 犯了这个毛病，已改**。

**demo 入口**：`pnpm run build && pnpm run build:demo` → 装 `packages/demo`（本地路径）→ 插件页侧栏「组件」组 → **布局**。演示挂在整页右侧：A 内置头（图标 + 标题 + 右侧标签）、B 整块自定义头、C 无头 + 浮动关钮。

**定稿的面板模型（用户 2026-10-20 最终口径）**：

- `open(id?, { title, content })`：**组名 = 窗口，一对一**。不传 id = 默认窗口（保留名 `default`）；传 id 就开那一组。
- 该 id 已开 ⇒ **原位覆盖内容**（槽位、顺序、宽度都不变，不新增一栏）。
- 该 id 未开 ⇒ 新增一右栏；**已满 3 栏 ⇒ 拒绝**，不静默丢弃，返回失败结果供调用方提示/报错。
- 关掉任意一栏（如 default）后再开新组名（如 C）⇒ 允许，占用腾出的位置。
- 无 tabs、无 tab 条、无自动淘汰：**面板内部的标签切换是消费方自己的事**。
- 上限是 dock 参数，默认 3，调用方可设；宽度上另有一道物理闸（主区保底宽），先到者生效。

两条边界（属设计约束，不属硬伤）：

1. 分栏**必须由调用方放进自己的 flex 布局**，不能像 `Modal` 那样自挂 `document.body`（自挂只能遮盖、挤不窄）；
2. 「贴着宿主聊天正文的右栏」是宿主 `sidebarRight` 的地盘，**整页替换会话区的插件用不了**，本任务不做。
