## 结论

- **纠错（2026-10-19 21:2x）**：0.2.14「探针实证 `.dshpc-seg` 类名触雷」**作废**。`probe()` 在
  `document.querySelector(sel) === null` 时返回 `'none'`（`packages/demo/src/client/index.tsx`），
  而全仓没有任何代码给元素加过 `dshpc-segprobe` 类 ⇒ 那个 `none` 的含义是「页面上没有带该类的元素」，
  不是「规则不生效」。当时把 `none` 当成结论，是误读。
- 站得住的证据只有两条：① 同一份注入文本里 `.dshpc-btn` 规则在 CSSOM 里且生效；② `.dshpc-seg`
  在 CSSOM 里查不到（0.2.10 `rule:no-rule`）且元素 computed `display:block`。
  文本侧已扫描：`SEGMENTED_CSS` / `BUTTON_CSS` 等八个常量括号与注释全平衡（`depth=0`、`issues=none`），
  ⇒ 不是文本残缺。根因**仍未定**。

- 可验证事实：`pnpm run build` / `pnpm run build:demo` 通过；`pnpm test` 39 项全绿；
  `koc-codelint` 六层全过（9 个文件）。
- 2026-10-19 二轮（0.2.2）：
  - 预览页滚不动：`DemoPage` 根节点 `alignItems: 'flex-start'` 使两侧高度退化成内容高 ⇒ main 的
    `overflowY:auto` 没有可滚高度、溢出被宿主裁掉。改 `stretch` + main `height/minHeight:0`
    （`packages/demo/src/client/index.tsx:44-84`）。
  - block + 前置图标「文字看着偏右」：新增 `--btn-pad`，`.dshpc-btn--block.dshpc-btn--icon-start`
    在右内距补 `1.2em + 6px`，可用盒左移同量 ⇒ 文字落回视觉中心（`controls-css.ts` BUTTON_CSS 段）。
  - demo 讲清 icon：`icon` 收的是 ReactNode（官方图标 / 自绘 SVG / 单个字符各演示一颗），
    不是名字也不是 class；「icon only」标签改为「纯图标钮」。
  - 补 FieldHint 三处挂载演示（标题后 / 按钮后 / 文字后）。
- 2026-10-19 官方 Tooltip 源码核实（`@deepseek-ai/dsh-client-ui-primitives@0.2.1-rc.2`，
  `lib/types/Tooltip.d.ts` + `Tooltip.module.css`）：side = `right | bottom | top`（无 left），
  align = `center | end`（仅上下气泡生效），另有 `gap` / `maxWidth` / `portal` / `delayMs` /
  `openOnClick`；气泡 `position:fixed`，portal 时 z-index 1100，底色 `--dsw-alias-tooltip-bg`。
- 未验证：真实宿主里的最终观感（本机无宿主进程，无法截图比对）；hover 幅度按 token 计算，
  用户若仍觉不够可再调 `--dshpc-*-hover` 的混色比例。
