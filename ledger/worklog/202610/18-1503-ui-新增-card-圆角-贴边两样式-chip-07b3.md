## 背景

用户给了两张截图，要把其中的「条目卡片」抽象成 UI 控件，原话要点：

- 一个四周圆角 + 1px 边框；一个四周无圆角、**左边一条通高竖线**
- **两种样式是两种控件**，「消费方要用哪个拖哪个」，**不要合在一起**（否决了我最初的 variant 方案）
- 右侧小箭头可传参控制需不需要
- 颜色可传固定档（green/yellow/red/灰…）或自定义
- 色条跟着高度自适应、上下留距
- 内容排版随便调用方写
- **中英文必须支持；亮暗风格必须能跟随切换**

## 过程

**按用户要求拆成两个独立组件**（不是 `Card` + `variant`）：

| 组件 | 外观 | 色条 |
|---|---|---|
| `Card` | 圆角 + 1px 边框 | 短条，上下留距 8px |
| `StripCard` | 无圆角、无边框 | 通高（贴顶到底） |

内部共享一个 `CardShell`（kind 参数），对外两个独立导出——使用层面二选一，维护层面只有一处。

**色条档位**照 `dsh-task-dispatch-table/src/client/records-timeline.tsx` 的 tone 模式：
一个 CSS 变量 `--card-accent` 切档，不写 5 套规则；档位直接映射**已有 token**
（business / success / warning / danger / fg-4），**不新增 token**。也接受任意 CSS 色值
（传字符串时走 `style` 设变量）。

**色条自适应高度**：绝对定位 + `top/bottom`，不参与文档流 ⇒ 内容多高它多高；
上下是否留距由外观决定（`Card` 8px、`StripCard` 通高）。

**中英文**：折叠按钮的 aria-label 走 `t('cardToggle')`（内置字典加中英两条）。

**亮暗跟随**：所有颜色一律吃 token（`surface-1` / `border` / `border-faint` / 5 个语义色），
**没有写死任何颜色值** ⇒ design 的 token 深色段（`body[data-ds-dark-theme]`）自动生效。

**顺带做了 `Chip`**（截图里到处是的小标签）：token 用现成的 `--tdt-chip-bg` / `--tdt-chip-bg-hover`，
传 `onClick` 才是可点的。

## 结论

`ui` 新增三个导出：`Card` / `StripCard` / `Chip`（ui 入口导出数 37 → 41），
自检 33 → **35 条**全过，CSS 六处类名落盘确认。
