## Process

- 成熟库的 DOM 路线（2026-10-30 调研结论）：语义 `<table>` = Ant Design / MUI / Chakra / Bootstrap /
  Element Plus（表头与表体是两张同步 colgroup 的 table）/ shadcn 的 Data Table（TanStack 无头 + `<table>`）；
  div / 绝对定位网格 = AG Grid、Fluent DetailsList，为虚拟滚动与自由列操作；TanStack Table 本身只管逻辑、不选 DOM。
