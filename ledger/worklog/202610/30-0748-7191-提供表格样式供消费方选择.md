## Process

- 用户 2026-10-30 拍板：第一档正是参考稿；要按项目规范、给后续 2~3 档留空位，消费方引哪个只打包哪个。
- 命名与分包（定案）：**同族独立组件** `Table` / 预留 `TableGrid` / `TableZebra`，**永不使用 variant** ——
  variant 会让多份皮肤 CSS 同时进包，违背「引哪个只打包哪个」。
- 文件分层：`src/ui/table-logic.ts`（纯逻辑，零 React 运行时依赖，node 可直测）/ `src/ui/table-shared.ts`
  （内部共享壳，只登记基础层 `table-core`）/ `src/ui/Table.ts`（只 import 自己的皮肤 `table-plain`）/
  `src/ui/controls/table.css`（结构 + 交互 + 空态）/ `src/ui/controls/table-plain.css`（第一档皮肤）。
- 可分离验证：esbuild 只引 `Table` 打 64.6 KB，`dshpc-btn` 出现 0 次（未带进 Button 等 CSS）；
  两份 CSS 常量无同名选择器（`test/css-contract.test.mjs` 全绿）。
- CSS 契约：皮肤选择器全挂 `.dshpc-table--plain` 下、基础层不复写；选中左条用背景渐变画（避开 tr 伪元素定位）；
  选中态选择器比 hover 多一条属性，悬浮不会盖掉选中。
- 自检：新增 `test/table.test.mjs` 6 条（扁平 / 两层 / 三层分组、叶子顺序、深度）；内置空态 key `tableEmpty`。
- 用户真机反馈（2026-10-30）：表格看不出边界 / 表头，右侧疑似被代码块挡住的列。原因两条：
  ① 列宽合计 988px 远超示例栏宽，`table-layout:fixed` 让列冲出容器、被右侧代码栏盖住；
  ② Plain 原设计只有极淡竖线、无外框无表头底，白底上边界确实糊。
  ⇒ 修正：Plain 加外框 + 灰底表头 + 表头下边线 + 10% 竖分隔 + 数据行 4% 极淡底线；
  demo 的表格示例改为占满整栏（代码移到底部 DocCode），外加 `overflowX:auto` + `minWidth:820`
  的滚动容器示范「超宽归调用方兜住」。静态渲染 + 浏览器截图复核通过（/tmp 临时页，已删）。
- 文档：`docs/help/ui.doc.ts` 加 `table` 章节（prose / api / code），
  `docs/design/structure.md`、`docs/requirements.md`（§2.2 / §6 / §7）同步。
- 用户第二轮反馈（2026-10-30）：色块间距太大 / 单元格能否装头像+名字+号码 / 表头能否多色 /
  每列能否居中 / 能否部分列无竖线 / 能否关掉左右外框 / demo 行数太少看不出斑马 / 空态别拆两个 /
  「Name 左边没 border 是不是没写好」，并要求「按最规范最通用的方法全支持、不要复杂」。
  ⇒ 第二版实现（配置面三层）：
  - 表级：`density`（compact 36 / default 44·48 / comfortable 52·60）、`striped`、`borders`（all / x / none）；
  - 列级：`align`、`divider`（关该列左竖线，首列恒不画）、`padding`（水平内距 px，内联 style 覆盖）、
    `headerTone`（12 个语义色，全部映射 token 的 soft 底 + 实色字，暗色自动跟随）；
  - 单元格：`ReactNode`（任意内容，含头像+姓名+编号的多行排版）或 `{ content, colSpan, rowSpan, align }`；
    缺 key = 不渲染、给上一行 rowSpan 让位；要空格显式传 null；
  - 分隔线改**按列声明**：组件给格子打 `data-divider='left'`，皮肤只对它有 border-left。
    删掉 `.cell + .cell` 相邻兄弟选择器 —— 它就是「每行首格没有左线」的根因，且跨列后会画错位。
  - 斑马纹放基础层（`.dshpc-table--striped` + `--dshpc-plate`），皮肤行态规则加 `.dshpc-table__body`
    上下文压过它（hover / 选中永远优先）。
  - demo：主表 12 行、多色表头（Patient 蓝 / Status 绿）、Age 列 divider:false + 居中、
    姓名格头像+名字+MRN、斑马 + 选中；主表下方同区块接空表（不再单独一个 Example）；
    第二表展示 compact + borders:none + rowSpan（缺 key 让位）+ colSpan。
- 自检：`test/table.test.mjs` 加第 7 条（单元格对象判别，React 元素靠 $$typeof 排除）；
  静态渲染复核 data-divider / data-header-tone / colSpan / rowSpan / density·borders·striped class 均正确
  （/tmp 临时脚本，已删）。
- 用户第三轮反馈（2026-10-30）：默认内距偏大，要求改小；把参考图上的内容形态都放进 demo。
  ⇒ 默认水平内距 16 → 12px（space-3），compact 12 → 8px（space-2），comfortable 保持 16px；
  demo 主表加 Modality（色标签，列 padding 8）与 Flags（多标签，列 padding 8）两列，
  连同头像 + 名字 + MRN、状态胶囊、行尾按钮，覆盖参考图里的内容形态。
