  高亮、双数行点了没反应，且「有时再点能取消、有时不能」；③ 要「通栏」样式 —— 一个表格里放多个
  工作区：通栏标题 → 表头 → 任务行 → 下一个通栏 → 表头 → 任务行。
  ⇒ 三项逐条落地：
  - **双数行点不亮 = 斑马纹特异性事故**：基础层斑马纹原写法
    `.dshpc-table--striped .dshpc-table__body .dshpc-table__row:nth-child(even)` 是 4 级
    （2 类 + 1 类 + 1 伪类），皮肤选中也是 4 级；而 `Table` 先登记皮肤、`tableShell` 后登记基础层
    ⇒ 偶数行永远被斑马纹盖住。删掉多余的 `.dshpc-table__body`（降为 3 级）后，皮肤的 hover（5 级）
    与选中（4 级）恒压过它，与注入顺序无关。
  - 「有时能取消、有时不能」= demo 只做了 `setSelected(row.key)`，从不 toggle；有的行看起来「取消」
    其实是被斑马纹盖住/没盖住造成的错觉。demo 改成 `setSelected(prev => prev === row.key ? null : row.key)`，
    `selectedKeys` 由 `selected === null ? [] : [selected]` 派生。
  - 悬浮 → `--dshpc-open-bg-soft`（浅 .05 / 暗 .08），选中 → `--dshpc-business-soft`
    （8% / 暗 5%）并保留左侧 3px `--dshpc-business` 竖条；不再用 `--dshpc-open-bg`（.10 / .18）。
  - **通栏分组**：`table-logic.ts` 加 `TableGroup { key, title, rows }`；`table-shared.ts` 支持
    `groups`（与 `rows` 二选一）——每组一个 `<tbody>`，内含一行 `colSpan = 叶子数` 的通栏 `<th>`
    + 这一组自己的表头 + 数据行；分组模式不渲染 `<thead>`（一个 table 只有一个）。
    基础层加 `.dshpc-table__group-cell`（`--dshpc-surface-sunken` 底、600 字重、组间 `border-top`，
    首组 `:first-of-type` 不画以免与外框成双线）；`ui/index.ts` 导出 `TableGroup`。
  - demo 新增 `Groups · 通栏` 示例（工作区 A 3 行 / 工作区 B 2 行）+ i18n `tableGroupHint`；
    `docs/help/ui.doc.ts` 补 prose 段与 `groups` API 行、`tableExample` 补通栏片段；
    `docs/requirements.md` §2.2 补「结构级 groups」与「行态优先级」两条硬约束。
