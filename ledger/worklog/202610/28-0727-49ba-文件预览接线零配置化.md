## 背景

用户 2026-10-28 问「消费方为什么一定要内联 inject 把服务存起来、为什么还要自己写 flex 行」，拍板两条：
① 读文件服务该由核心接线（`connectHost` 已有先例，同 `workspaceList`）；
② `mount` 那层不该要求消费方自己写样式，「加个标签就行」。目标口径 = 消费方只写
`connectHost(ctx)` + `openFilePreview({ mount, path })`。

- 真机发现动效 bug：侧栏已展开时点别的文件，会把「关掉旧预览 + 重建」走一遍 ⇒ 展开动效重播
  （`.dshpc-dock__panel` 的 `animation:dshpc-dock-in` 绑在元素创建上）。修法：`activePreview`
  记住 mount 与 `draw()`，**同 mount 再开只重画**（元素不重建 ⇒ 动效天然只播一次，拖过的宽度也保住）；
  内层 `PreviewBody` / `FileBrowser` 以 path 作 key，换文件即重挂、状态不串。
  `test/explorer.test.mjs` 同步那条源码自检并新增「同 mount 复用」一条。
- 用户 2026-10-28 再报：换文件把**拖好的宽度**重置了。根因同一处 —— 只要没走到复用分支就是
  整份重建（新 dock = 新宽度状态）。第一版按 `mount === opts.mount` 判断太脆（换个入口拿到不同容器
  就退回重建），现改成：**只要已有预览就一律复用**，`adopt()` 就地把挂载体搬进新容器（`appendChild`
  即移动，React 根不动），`keepWidth()` 换内容前把当前渲染宽度写回 dock 状态并作为 `pinnedWidth`
  兜底 `width` prop；低于 `minWidth` 的量测得值（入场动画中间态）忽略。
- 用户再报：**收起后再点文件不弹出**。收起只是面板退出布局（`ids` 清空、容器还在），复用分支
  只换内容 ⇒ 看着像没反应。修法：`draw()` 开头 `dock.isCollapsed → dock.expand`
  （收起态 `ids` 为空，不受 `maxPanels` 闸限制；宽度由 `collapsePanel/expandPanel` 原样保留）。
- 发版 `v0.7.1`（两包同号；顺手修掉自 757a8a6 起就红的 version-sync）。

## 结论

- 消费方口径落到两句：`connectHost(ctx)` 一次接线；`openFilePreview({ mount, path })`。
- 三条真机口径全部落地：换内容不重播展开动效、不动用户拖拽的宽度、收起态自动展开。
- 验证：`pnpm build` / `typecheck` 干净、`pnpm test` 131/131 全绿、`codelint` 全过；
  用户 2026-10-28 真机验收通过；发版 `v0.7.1`（7ae6303，tag 已推）。
- 留坑：核心 store 无订阅（服务晚到时已打开的预览不会自愈）；`mount` 若被刻意设成非 flex 布局
  （如 grid）会被补成 flex，关闭即还原。
