# demo 的真实样例文件

这四个文件是**仓库里的真文件**，不是 mock：demo 装在宿主里以后，「工作区浏览」页的按钮
直接把它们交给 `remote.workspaceFiles` 去 list / read —— 走的链路和任何真实工作区文件一样。

| 文件 | 用来看什么 |
|---|---|
| `README.md` | Markdown 渲染（渲染 ⇄ 源码切换） |
| `demo.html` | iframe 沙箱渲染（CSP + 禁标签清单与官方同款） |
| `sample.js` | 代码高亮 + 源码态分页读 |
| `sample.css` | 纯文本渲染（未知扩展名按文本读） |

面包屑、▾ 选层、目录树、复制路径、刷新，都可以在这个目录上对着真数据点一遍。
